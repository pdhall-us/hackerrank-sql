# Weather Observation Station 6

## 📝 Problem

Query the list of `CITY` names starting with vowels (i.e., `a`, `e`, `i`, `o`, or `u`) from the `STATION` table.

The result cannot contain duplicates.

## 📋 Table: STATION

| Column | Type |
| ------ | ---- |
| ID | NUMBER |
| CITY | VARCHAR2(21) |
| STATE | VARCHAR2(2) |
| LAT_N | NUMBER |
| LONG_W | NUMBER |
