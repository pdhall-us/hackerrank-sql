# Weather Observation Station 3

## 📝 Problem

Query a list of `CITY` names from the `STATION` table for cities that have an even `ID` number.

Print the results in any order, but exclude duplicates from the answer.

## 📋 Table: STATION

| Column | Type |
| ------ | ---- |
| ID | NUMBER |
| CITY | VARCHAR2(21) |
| STATE | VARCHAR2(2) |
| LAT_N | NUMBER |
| LONG_W | NUMBER |
