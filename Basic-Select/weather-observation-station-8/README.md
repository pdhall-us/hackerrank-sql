# Weather Observation Station 8

## 📝 Problem

Query the list of `CITY` names from the `STATION` table which have vowels (i.e., `a`, `e`, `i`, `o`, and `u`) as both their first and last characters.

The result cannot contain duplicates.

## 📋 Table: STATION

| Column | Type |
| ------ | ---- |
| ID | NUMBER |
| CITY | VARCHAR2(21) |
| STATE | VARCHAR2(2) |
| LAT_N | NUMBER |
| LONG_W | NUMBER |
