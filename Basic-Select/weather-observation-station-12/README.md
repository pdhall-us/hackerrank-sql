# Weather Observation Station 12

## 📝 Problem

Query the list of `CITY` names from the `STATION` table that do not start with vowels and do not end with vowels.

The result cannot contain duplicates.

## 📋 Table: STATION

| Column | Type |
| ------ | ---- |
| ID | NUMBER |
| CITY | VARCHAR2(21) |
| STATE | VARCHAR2(2) |
| LAT_N | NUMBER |
| LONG_W | NUMBER |
